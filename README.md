# תהילים בדרך

אפליקציית ווב (PWA) שמקריאה תהילים פסוק אחר פסוק, עם הפסקה אחרי כל פסוק כדי לחזור אחריו, למשל בנסיעה.

## תכונות
- תהילים יומי לפי החודש העברי (כולל כ״ט בחודש חסר) או לפי ימי השבוע, או כל טווח פרקים
- הפסקה לחזרה שאורכה יחסי לאורך הפסוק (ניתנת לכיוון, או הקראה רצופה)
- השם המפורש מוקרא "אדני" (ו"אלהים" במקומות המנוקדים כך); בכתיב/קרי מוקרא הקרי
- כפתורים גדולים, מסך נשאר דולק בזמן הקראה, תמיכה בכפתורי מדיה/בלוטוס
- זוכרת איפה עצרת, ועובדת גם בלי אינטרנט אחרי הטעינה הראשונה

## שימוש
פותחים את האתר בטלפון ובוחרים "הוסף למסך הבית". ההקראה משתמשת במנוע הדיבור של הטלפון, ולכן צריך קול עברי מותקן:
- **אנדרואיד:** הגדרות ← נגישות / שפה ← פלט טקסט לדיבור ← Google ← התקנת נתוני קול ← עברית
- **אייפון:** הגדרות ← נגישות ← תוכן מוקרא ← קולות ← עברית

## פיתוח
אתר סטטי ללא שלב build. להרצה מקומית: `npx serve .`

הטקסט נמצא ב-`data/tehillim.json` ונוצר בעזרת `node scripts/build-data.mjs`.
