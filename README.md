# תהילים בדרך

אפליקציית ווב (PWA) שמקריאה תהילים פסוק אחר פסוק, עם הפסקה אחרי כל פסוק כדי לחזור אחריו, למשל בנסיעה.

## תכונות
- תהילים יומי לפי החודש העברי (כולל כ״ט בחודש חסר) או לפי ימי השבוע, של היום או של כל יום אחר, או כל טווח פרקים
- התאריך של היום, עברי ולועזי, בראש המסך
- "הרצף שלי" (בהגדרות): רשימה של חלקים שמוקראים ברצף, למשל תהילים יומי לפי החודש, אחריו לפי השבוע, ואחריו פרקים כ, קכד ו-קנ. האפליקציה נפתחת על הרצף
- הפסקה לחזרה שאורכה יחסי לאורך הפסוק (ניתנת לכיוון, או הקראה רצופה)
- שני קולות מוקלטים, עומר וליאת, שקוראים כל מילה בהטעמה הנכונה לפי הטעמים (מלעיל ומלרע) ובשווא נע במקומו. ההקראה הוכנה מראש לכל הפסוקים, ולכן היא זהה בכל טלפון ולא תלויה בקולות שמותקנים בו
- אפשר גם לבחור בקול של הטלפון (עם הטעמה ניסיונית ב-SSML באפליקציית האנדרואיד)
- השם המפורש מוקרא "אדני" (ו"אלהים" במקומות המנוקדים כך); בכתיב/קרי מוקרא הקרי
- כפתורים גדולים, מסך נשאר דולק בזמן הקראה, תמיכה בכפתורי מדיה/בלוטוס
- פקודות קוליות (כפתור המיקרופון): "עבור לפרק כג" / "החלף לפרק קכא" / "חזור לפרק א", "פסוק הבא", "פסוק קודם". את מספר הפרק אפשר לומר כמספר (מאה עשרים ואחת) או בשמות האותיות (קוף כף אלף). זיהוי הדיבור דורש אינטרנט
- זוכרת איפה עצרת, ועובדת גם בלי אינטרנט אחרי הטעינה הראשונה

## שימוש
פותחים את האתר בטלפון ובוחרים "הוסף למסך הבית".

**הקולות המוקלטים:** האפליקציה מורידה את הפרקים ברקע כל עוד היא פתוחה, קודם את הקריאה של היום ואחר כך את השאר, ושומרת אותם לשימוש בלי אינטרנט. ב-APK כבר כלולים הפרקים הראשונים של כל יום בשבוע ושל כל אחד מחמשת הספרים (א, ל, מב, נא, עג, צ, קז, קכ), כך שאפשר להתחיל מיד. פרק שעוד לא ירד, כשאין חיבור, מוקרא בקול הטלפון.

**קול הטלפון:** משתמש במנוע הדיבור של הטלפון, ולכן צריך קול עברי מותקן:
- **אנדרואיד:** הגדרות ← נגישות / שפה ← פלט טקסט לדיבור ← Google ← התקנת נתוני קול ← עברית
- **אייפון:** הגדרות ← נגישות ← תוכן מוקרא ← קולות ← עברית

## אפליקציית אנדרואיד (APK)
את קובץ ה-APK העדכני מורידים מדף [Releases](https://github.com/ymalka82810/tehillim-whisper/releases/latest) (tehillim.apk), ופותחים אותו בטלפון. בפעם הראשונה צריך לאשר "התקנה ממקורות לא ידועים".

באפליקציה ההקראה עוברת דרך מנוע הדיבור של אנדרואיד. אם חסר קול עברי, ההגדרות נפתחות אוטומטית עם כפתורים להתקנת הקול, לפתיחת הגדרות ההקראה של הטלפון, ולהתקנת מנוע Google (למשל בטלפוני סמסונג).

**עדכונים:** האפליקציה בודקת בכל פתיחה אם יש גרסה חדשה ומציגה כפתור "עדכן עכשיו" (אפשר גם לבדוק ידנית בהגדרות). הגרסה החדשה מותקנת מעל הקיימת, בלי הסרה, כי כל הגרסאות חתומות באותו מפתח ומספר הגרסה עולה בכל בנייה.

ה-APK נבנה ונחתם אוטומטית ב-GitHub Actions בכל push ל-main (`.github/workflows/android.yml`). הקוד של הרכיב ב-Java: `android/app/src/main/java/.../NativeSpeechPlugin.java`.

## פיתוח
אתר סטטי ללא שלב build. להרצה מקומית: `npx serve .`

הטקסט נמצא ב-`data/tehillim.json` ונוצר בעזרת `node scripts/build-data.mjs`.

### הקולות המוקלטים
נוצרים מהטקסט ב-`scripts/audio/render.py` (צריך [uv](https://docs.astral.sh/uv/)): Phonikud ממיר כל פסוק לתעתיק IPA עם ההטעמה מהטעמים, ו-Pocket TTS מקריא אותו. כל פסוק נבדק לפי קצב הדיבור שלו, וקטע שנשמע קטוע או ארוך מדי נוצר מחדש.

```
cd scripts/audio
mkdir models && curl -L -o models/pocket-tts-english-ipa.onnx https://huggingface.co/thewh1teagle/pocket-tts-onnx/resolve/main/pocket-tts-english-ipa.onnx
uv run render.py omer    # כשעה וחצי למעבד רגיל; ממשיך מאיפה שעצר
uv run render.py liat
```

התוצאה: `audio/<voice>/<ccc>.bin` (כל פרק קובץ אחד, הקטעים ברצף, קטע 0 הוא הכרזת הפרק) ו-`audio/index.json` עם אורכי הקטעים. אחרי שינוי בטקסט מריצים שוב, ורק הפסוקים שהשתנו נוצרים מחדש.
